# discussi0n

The discussion hub for [Foundation-0](https://github.com/Foundation-0):
announcements, ideas, questions, and open research review. The code lives
in the research repos; the conversation lives here.

👉 **[Go to discussions](https://github.com/Foundation-0/discussi0n/discussions)**

## Where to post

| Category | Use it for |
|---|---|
| 📣 Announcements | Releases, preprints, new tracks (maintainers only) |
| 💬 General | Anything Foundation-0 that fits nowhere else |
| 💡 Ideas | Half-formed questions and hunches |
| 🙏 Q&A | Ask; mark the answer when you get one |
| 📊 Polls | Decisions the `core` team puts to a vote |
| 🙌 Show and tell | Demos, figures, site updates |
| 📝 Research review | Open review of a result: errors, gaps, failed replays, missing prior art, wrong labels *(to be added by an owner under Settings — the API cannot create categories)* |
| 🧭 Track proposals | Propose a new open track: question, checker sketch, score *(same as above)* |

## Discussions vs issues vs PRs

- **Discussion:** exploring, questioning, reviewing in the open.
- **Issue:** a tracked defect or task in a specific repo.
- **PR:** a concrete change. One result per PR (see the org PR template).
- Reviews that hold get recorded in the repo's `docs/review-ledger.md`;
  link the discussion when you do.

## House rules

Our [Repository Standard](https://github.com/Foundation-0/.github/blob/main/REPO-STANDARD.md)
applies to words too: label claims PROVEN / VERIFIED / KNOWN / CONJECTURE,
"not found" is never "new", no hype, disclose AI assistance, credit
everything you build on.
